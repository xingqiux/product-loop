# 构思阶段的反问清单

构思要想全，检查只查一致。这份清单是构思时 AI 对自己和对用户的反问，按职能分。问题越多越好。前两组的答案写进主线的前几个部分。后面十二组的答案写进主线的设计规范，检查阶段对着它查一致性。答不出来的问题标待定，不硬编。

用法：

1. 每个职能先问这个产品有没有这一块。没有的写一句「无」和原因。
2. 有的就把下面的问题过一遍，每个问题一行答案。答案要能被检查：能指到一个值、一个规则、一个例子。
3. 设计规范的十二个部分各占主线里的一个三级标题，标题就是下面的名字，不改字。命令按标题认它们。

## 主线前几个部分的反问

### 定位与人

1. 这个产品一句话是什么？为什么现在存在？承诺什么？
2. 给谁用？他们上次做这件事是什么时候、用什么、花了多久、忍受了什么？
3. 他们现在用什么凑合？为什么凑合的东西不够？
4. 谁买单、谁天天用？两者不是一个人时，谁说了算？
5. 如果这个产品明天没了，用户会去用什么？

### 任务与场景清单

1. 用户要完成的事有哪几件？每件的情境是什么？
2. 每件事的开头和结尾是什么？结尾用户手里拿到什么？
3. 哪件事是产品卖的？其余的是它的前提还是延伸？
4. 每个场景过五条判据了吗：有动机、有说服力、可信、够复杂、结果能判定？
5. 第一次进来、空的时候、出错的时候、等的时候，各是什么样？
6. 不做什么？每条一句原因。这一版的胃口是多久？

## 设计规范十二个部分的反问

### 信息结构

1. 每一屏用户第一眼要看到的三样是什么？
2. 层级怎么分：一级、二级、正文，各用什么区分？
3. 导航回答"我在哪、我能去哪"吗？返回去哪？
4. 列表和详情的关系是什么？从哪进、回哪去？
5. 同一个对象在几处出现？名字一致吗？
6. 哪些信息永远在屏上，哪些要展开才有？

### 配色

1. 用哪套色？为什么是这套，表达什么？
2. 主色、辅色、强调色各是什么值？成功、警告、错误这三种语义色各是什么值？各管什么？
3. 灰阶几档？每档用在哪？
4. 没有颜色的地方是什么意思？灰等于禁用吗？
5. 深色模式有吗？每个颜色在深色下对应什么？
6. 对比度按哪个标准？正文和小字各要多少？
7. 用哪个 skill 或工具出色板？

### 字体排版

1. 用哪几款字体？中文和数字各用什么？回退栈是什么？
2. 字号几档？字重几档？每档用在哪？
3. 行高、字距的规则是什么？
4. 正文一行多宽？
5. 数字对齐用等宽数字吗？
6. 表格、代码、标签各用什么样式？

### 布局

1. 网格是几列？间距用哪几档？
2. 在窄（约 420）、中（约 1000）、宽（约 2000）三个宽度下各怎么排？
3. 卡片、行、面板的圆角和边框规则是什么？
4. 什么时候用卡片，什么时候用列表，什么时候用表格？
5. 留白怎么给？内容贴哪边？

### 交互

1. 每种控件长什么样？控件包括按钮、链接、下拉、标签页、开关和输入框。选中、悬停、禁用、加载各是什么样？
2. 点了会发生什么，怎么让用户提前知道？
3. 哪些操作可以撤销？怎么撤销？
4. 哪些操作要确认？确认的文案怎么写？
5. 拖拽、快捷键、右键有吗？规则是什么？
6. 表单：必填怎么标？错误在哪显示？什么时候校验？
7. 用哪个组件库或 skill 做？自己写的话，组件清单是什么？

### 动效

1. 哪些地方要动效？哪些地方明确不要？
2. 手感是一个什么词：干脆、柔和、弹跳？用哪种缓动曲线、多长时长？
3. 进入、退出、切换、加载各用什么动效？
4. 减少动态效果时怎么办？
5. 用动效库还是手写？用哪个 skill 做？

### 图标和 SVG

1. 图标用哪套？线宽、圆角、尺寸是多少？
2. 没有现成图标时谁画？画的规则是什么？
3. 插画和缩略图的风格是什么？占位图长什么样？
4. SVG 怎么写：手写、工具导出、还是让 AI 画？用哪个 skill 学画？

### 文案

1. 定位定的口气是什么？正式还是口语？用不用感叹号？
2. 按钮上写动作还是写对象？
3. 空状态、错误、等待各说什么？说给谁听？
4. 名字怎么起：用用户的词还是系统的词？英文 id 允许出现吗？
5. 符号规则：用不用间隔号、破折号、括号？

### 给 AI 的界面

1. 这个产品有 agent 用的一面吗？agent 用的可能是命令、文件、接口或提示词。
2. agent 看到的名字和人看到的一样吗？
3. 命令和输出的格式是什么？错误怎么报？
4. agent 需要问人的时候，用什么渠道问？
5. 人用 CLI 是什么感觉？AI 用 CLI 是什么感觉？两者差在哪？

### 状态

1. 空：第一次进来是什么样？引导去哪？
2. 等：加载中、生成中显示什么？多久算太久？
3. 错：出错显示什么？用户能做什么？
4. 成：完成后自动做什么？用户要不要点一下？
5. 断：外部服务不在、进程被杀、面板关掉，各怎么恢复？

### 无障碍

1. 键盘能走完主流程吗？焦点看得见吗？
2. 对比度达标吗？只靠颜色区分的地方有没有第二个信号？
3. 触屏、鼠标、键盘各怎么用？

### 做法和阶段

1. 这些设计分几个阶段做？每个阶段交出什么？
2. 每个阶段用哪些 skill、哪些工具、哪些现成的设计系统？
3. 宿主平台已经有的机制有哪些？能不能直接用，不自己做？
4. 哪些先做低保真验证，哪些直接做？
