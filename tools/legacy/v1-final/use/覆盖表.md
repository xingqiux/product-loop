# 覆盖表（产品循环 skill 自己的）

面向人的那一面是报告网页，用 `walk-report.mjs` 走；面向 AI 的那一面是构建校验，用 `../check-samples.py` 试。

| 页面、入口、操作、状态 | 被哪个场景用到 | 尺寸 |

| 页头：这一轮看过哪几屏 | 中途接手 | 小 |

| 疑问卡：看到、待决定、选项、我的看法、备注 | 回答疑问 | 中 |
| 卡片右边没有东西时一栏到底 | 回答疑问 | 小 |
| 底部：还剩几条、随时能写的输入框、复制回复 | 回答疑问 | 中 |
| 更改：改前改后图，点图放大 | 验收更改 | 小 |
| 粘贴截图：缩略图和〔图 1〕、正在存图、点缩略图放大、复制结果带图的标识 | 截图反馈（存图用替身） | 中 |
