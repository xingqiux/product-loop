# 主线

构思的产物。十样写满、每样用户点过头，才算构思结束。每样后面的括号写它来自哪种方法，出处在 `references/阶段 skill 设计.md`。

## 1 一句话新闻稿

产品做什么、给谁、为什么现在存在、承诺什么。一到三句。这就是定位，文案口气以它为准。（逆向工作法）
例：给企业客户用的报表工具。财务不用等 IT 就能自己出周报。正式、简短、不出现口语。

## 2 给谁用

每类人一段。只写行为，不写意见：他们现在怎么做这件事、上次是什么时候、用什么凑合、忍受什么。（《The Mom Test》）
例：财务专员。每周一上午用三张 Excel 拼周报，上次花了两小时，拼错过一次数字。

## 3 要完成的任务

一任务一行：情境 → 要完成的事 → 现在的凑合办法 → 忍受的成本。（任务视角）

| 情境 | 要完成的事 | 现在怎么凑合 | 忍受什么 |
| --- | --- | --- | --- |
| 周一早上 | 把上周数据变成一页周报 | 三张 Excel 手拼 | 两小时，会拼错 |

## 4 场景清单

每个任务一到多个场景。场景 1 是产品卖的那条。每步写"用户做什么 → 该看到什么"。每个场景过五条判据：有动机、有说服力、可信、够复杂、结果能判定。（卡纳的场景测试）

场景 1（任务 1，产品卖的就是这条）：
1. 用户做什么 → 看到什么
2. …

场景 2（第一次进来、空项目）：
1. …

场景 3（回头看、改、管理已有的东西）：
1. …

场景 4（等待和出错：加载中、失败、进行中、外部服务不在）：
1. …

一个页面、一个按钮要么在某个场景上，要么在"不做什么"里。

## 5 不做什么和胃口

明确不做的功能和场景，每条一句原因。（《Shape Up》）
- 例：不做多人协作。原因：给谁用里没有第二个人。

胃口：这一版愿意花多少时间。到点没做完的砍掉，不延期。
例：两周。

## 6 交付线

客户拿到手第一天必须能做到的几条，每条能用脚本验证。（逆向工作法）
- 例：新客户装好后，30 分钟内能让第一个学员完成一次对练并拿到评分。

## 7 四个风险

各一句回答，答不出的进待定。（卡根的四大风险）
- 价值：用户会不会用？证据是什么？
- 可用：用户会不会用得明白？
- 可行：工程上能不能做出来？卡在哪？
- 商业：和销售、品牌、法务、财务合不合得上？只写一句话定位的项目可以跳过。

## 8 常见问题与待定

写前七样时冒出来的问题。答了的写答案；没答的标"待定：问谁、什么时候"。（逆向工作法的常见问题）
- 问：…　答：…
- 待定：…　问谁：…　什么时候：…

## 9 事前验尸

假设一年后这个产品失败了。最可能的三个原因，各配一句现在就做的对策。（克莱因的事前验尸）
1. 原因：…　对策：…
2. …
3. …

## 10 设计规范

按 `references/构思反问.md` 的职能问一遍，每个答案是一个值、一条规则或一个例子。检查阶段的交互一致性对着这里查。没有的职能写"无"和原因。

| 职能 | 规则 | 例 |
| --- | --- | --- |
| 信息结构 | 每屏首屏三样：… | 我的设计：搜索、排序、新建 |
| 配色 | 主色 / 强调色 / 语义色 / 灰阶几档；灰不等于禁用 | … |
| 字体排版 | 字号几档、字重几档、行高 | … |
| 布局 | 网格列数、间距档位、三个宽度下的排法 | … |
| 交互 | 每种控件的默认、悬停、选中、禁用、加载 | 选中是主色实底 |
| 动效 | 手感一个词、缓动、时长；哪里不要动效 | 干脆，150 毫秒，只用于展开收起 |
| 图标与 SVG | 哪套图标、线宽、圆角；没有现成的谁画 | … |
| 文案 | 口气、按钮写动作、符号规则 | 不出现"·" |
| 给 AI 的界面 | 命令和输出格式、错误怎么报、agent 怎么问人 | 问人用 atlas-visualize |
| 状态 | 空、等、错、成、断各显示什么 | … |
| 做法 | 分几个阶段、每阶段用哪些 skill 和现成机制 | … |

## 覆盖表

在 `scripts/use/覆盖表.md`。页面、入口、操作、状态、接缝各占一行，写被哪个场景用到。没用到的就是使用的缺口。
