# 覆盖表对照

这是第二期的对照，留作历史。这个软件现在的覆盖表是 `scripts/use/覆盖表.md`，页面、区块、入口、操作、状态、命令和交接处都在里面，以它为准，由 `ploop use coverage` 核对。下面表里写的场景对应，以那张表和 `design/主线.md` 为准。

本文逐行对照 skill 自己的覆盖表（`~/.agents/skills/product-loop-bate/scripts/use/覆盖表.md`，旧 skill 目录下，正文 30 行）和新工作台（`packages/web/`）。这是第二期计划第 22 步：覆盖表每一行，要么写明由新工作台哪个页面、哪个文件覆盖，要么写明不再需要的理由，供第二期验收第 26 条核对。

「怎么验证」一栏，已经有自动化测试的写测试文件。只能靠人在浏览器里走一遍的写场景编号（场景见 `design/主线.md` 的场景清单，代码在 `scripts/use/scenes/`，由 `pnpm use` 起浏览器跑）。两样都没有的写「无，要补」。「不再需要」的行不用验证，写「不适用」。
