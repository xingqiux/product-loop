# 术语对照

中文术语和代码里的名字一一对应，每个中文术语只对应一个英文名。依据是「10 工程规范与流程」第一节。

本文由程序生成，不要手改。名词取自 `packages/model/src/terms.ts`，名称表取自同一目录的 `names.ts`。
改了这两个文件以后，运行 `pnpm --filter @product-loop/model terms-doc` 重新生成。
