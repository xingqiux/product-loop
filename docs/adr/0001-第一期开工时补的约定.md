# 0001 第一期开工时补的约定

状态：已采用（2026-09-28）

## 背景

拆第一期步骤时，对着「软件设计」00 到 14 查出二十五处缺口和矛盾。有的是两份文档说法不一，有的是没写到能写代码的程度。

其中三处已经在设计文档里改正：

- 第 1 条，新正文的安装名字和切换时间。改了「08 版本与迁移」第八节第 3 条。
- 第 3 条，skill 问题的两条命令放在第一期。改了「11 分期计划」第五节。
- 第 2 条，S21 的场景原文。写这个软件自己的主线时改正，即第一期计划的第 66 步。

其余各条按下表的约定做，编号和第一期计划里的「约定第 N 条」对应。以后设计文档补上了，以设计文档为准，再回来把这里的状态改成「已并入设计」。

## 影响

- 第 8 条里 rethink 的转法，和用户对「旧页面转成新格式」的确认一起定。用户不同意时，改第 28 步的转换函数，不影响别的步骤。
- 第 4、5、10 条定了接口和命令行的形状，改动它们要同时改 model 的定义和两边的测试。
- 其余各条只影响各自列出的步骤。
