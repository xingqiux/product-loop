# 第二期计划

第二期交付工作台，替换第一期的旧模板，见「11 分期计划」第四节和「06 工作台」。
开工前要定的都已定下：配色用 a 黑白加蓝、「删」改成红色（决定 191）；字号、字体、圆角、间距、动效照原型（决定 190）；
复制来的组件进出场改用 Motion（决定 192）；只做浅色，颜色全部走主题变量（决定 193）。

做法和第一期后半段相同：一个会话按顺序做，相邻的步骤合并，每步做完跑 `pnpm check` 再提交（决定 177）。
第 21 步起可以派子代理并行做，第 23 步就是这样做的（决定 194）。
要起浏览器的测试放进 `pnpm use`。

## 一、步骤

### 后端（1–5）

| # | 做什么 | 完成标准 |
| --- | --- | --- |
| 1 | 事件流 `GET /api/v1/events` | 服务器推送事件，可按项目订阅。事件种类按前缀归到「05 接口」第五节的频道。每十五秒一条注释行。事务回滚不发 |
| 2 | 草稿和草稿的旧版本（第一期第 58 步挪来） | 加 draft、draft_revision 两张表。读、存、列旧版本、放回四个接口。「06 工作台」第四节的三个存旧版本的时机各有用例。存草稿发 `draft.saved` |
| 3 | 工作台的提交和「AI 已收到」 | 工作台按草稿提交，回复的行和对话里贴回的格式相同。命令行取走回复时发 `reply.received`，页面据此显示 |
| 4 | 工作台要读的接口补齐 | 项目列表带摘要；队列事项的状态变化和出现在哪几轮；决定来自哪一行回复 |
| 5 | 后端提供工作台 | 静态文件从 `app/<版本>/web/` 读，不认识的地址回到工作台的首页。`/p/<项目>/r/<轮次>` 由工作台显示，旧模板删掉。后一半等第 12 到 18 步做完再切，否则中间这段时间看不了页面。已随第 18 步切换，旧模板一并删掉 |
