# 第一期计划

本文把第一期拆成可以逐步验收的步骤。依据是「软件设计」00 到 14，范围和验收见「11 分期计划」第三节。开工时发现的文档缺口和补的约定，见 `docs/adr/0001-第一期开工时补的约定.md`。

所有步骤的通用完成标准如下：

- 每步结束时 `pnpm check` 通过，一步对应一个提交。提交说明按「10 工程规范与流程」第三节写，例如 `feat(model): …`。
- 命令行测试和使用代码这两层测试放进 `pnpm use`，`pnpm check` 只跑前三层。要起子进程的测试一律归到 `pnpm use`。
- 不用旧 skill 的 `land.py` 和页面。每一步以测试和提交为证据。
- 加表的步骤、改依赖目录的步骤必须串行合并。

大小的含义：S 约半天，M 约一到两天，L 约三天以上。
